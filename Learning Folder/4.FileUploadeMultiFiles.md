# 📤 Multer Multiple File Upload Guide

This guide explains how to upload multiple files using the **Multer** middleware in Express.js.

---

# 📚 Upload Methods

| Method                       | Upload Type                                        | Access                |
| ---------------------------- | -------------------------------------------------- | --------------------- |
| `upload.single("image")`     | Upload one file                                    | `req.file`            |
| `upload.array("images", 10)` | Upload multiple files with the same input name     | `req.files`           |
| `upload.fields([...])`       | Upload multiple file inputs                        | `req.files.fieldName` |
| `upload.none()`              | Accept only text fields                            | `req.body`            |
| `upload.any()`               | Accept any files _(Not recommended in production)_ | `req.files`           |

---

# 📁 Method 1 — Upload Multiple Images

Use this when users need to upload multiple images from one input.

## Route

```js
import { upload } from "../middleware/upload.js";

router.post(
  "/upload-images",
  upload.array("images", 10),
  uploadImagesController,
);
```

### Explanation

- `images` → Input field name
- `10` → Maximum number of files allowed

---

## HTML Form

```html
<form action="/upload-images" method="POST" enctype="multipart/form-data">
  <input type="file" name="images" multiple />

  <button type="submit">Upload Images</button>
</form>
```

### Note

The `multiple` attribute allows selecting more than one file.

---

## Controller

```js
const uploadImagesController = (req, res) => {
  console.log(req.files);

  const imageNames = req.files.map((file) => file.filename);

  console.log(imageNames);

  res.send("Images Uploaded Successfully");
};
```

# ⭐ Professional Approach

Instead of creating multiple Multer instances, use a **single Multer configuration** that automatically stores files in different folders.

---

## Storage Configuration

```js
const storage = multer.diskStorage({
  destination: (req, file, cb) => {
    const imageTypes = /jpg|jpeg|png|webp/;

    const ext = path.extname(file.originalname).toLowerCase();

    if (imageTypes.test(ext)) {
      cb(null, "public/uploads");
    } else {
      cb(null, "public/docs");
    }
  },

  filename: (req, file, cb) => {
    cb(null, Date.now() + "-" + file.originalname);
  },
});
```

---

## File Filter

```js
const fileFilter = (req, file, cb) => {
  const allowed = /jpg|jpeg|png|webp|pdf|doc|docx|txt|xlsx|xls|ppt|pptx/;

  const ext = allowed.test(path.extname(file.originalname).toLowerCase());

  if (ext) {
    return cb(null, true);
  }

  cb(new Error("Invalid File Type"));
};
```

---

## Upload Middleware

```js
const upload = multer({
  storage,
  fileFilter,
  limits: {
    fileSize: 10 * 1024 * 1024,
  },
});

export default upload;
```

---

## Route

```js
router.post("/upload", upload.array("files", 20), uploadController);
```

# 📤 Multer Multiple File Upload

Your current code uses **single file upload** with:

```js
upload.single("image");
```

If you want to upload **multiple files**, Multer provides three commonly used methods.

---

# 📚 Multer Upload Methods

| Method     | Description                                      |
| ---------- | ------------------------------------------------ |
| `single()` | Upload one file                                  |
| `array()`  | Upload multiple files with the same input name   |
| `fields()` | Upload multiple file inputs with different names |

---

# 📁 Method 1 — Upload Multiple Images (Same Input Name)

Use this method when users upload multiple images from one file input.

---

## multer.js

```js
import multer from "multer";
import path from "path";

const storage = multer.diskStorage({
  destination: (req, file, cb) => {
    cb(null, "public/uploads");
  },

  filename: (req, file, cb) => {
    cb(null, Date.now() + "-" + file.originalname);
  },
});

const fileFilter = (req, file, cb) => {
  const allowedTypes = /jpg|jpeg|png|webp/;

  const extName = allowedTypes.test(
    path.extname(file.originalname).toLowerCase(),
  );

  if (extName) {
    return cb(null, true);
  }

  cb(new Error("Only Images Allowed"));
};

const upload = multer({
  storage,
  fileFilter,
  limits: {
    fileSize: 2 * 1024 * 1024,
  },
});

export default upload;
```

---

```js
router.post("/multiple-upload", upload.array("images", 5), uploadController);
```

# 💡 Best Practice

- Use **`single()`** for one file uploads.
- Use **`array()`** when all uploaded files come from the same input.
- Use **`fields()`** when a form contains multiple file inputs with different names.
- Avoid **`any()`** in production because it accepts every uploaded file without restriction.

# 6. Error Middleware

import multer from "multer";

const errorMiddleware = (err, req, res, next) => {
console.error(err);

// Multer Errors
if (err instanceof multer.MulterError) {
return res.status(400).render("Link_nav/nodejs", {
err: [{ msg: err.message }],
image: null,
});
}

// Custom Errors
if (err) {
return res.status(400).render("Link_nav/nodejs", {
err: [{ msg: err.message }],
image: null,
});
}

next();
};

export default errorMiddleware;

# 7. app.js Order

Your middleware order should be:

// Built-in Middleware
app.use(express.json());
app.use(express.urlencoded({ extended: true }));
app.use(express.static("public"));

// Third-party Middleware
app.use(morgan("dev"));
app.use(cors());
app.use(helmet());

// Application Middleware
app.use(applicationMiddleware);

// Routes
app.use("/", fileUploadRoute);
app.use("/", fileUploadRouteM);
app.use("/", validationRoute);
app.use("/", middlewareRoute);
app.use("/", router);

// 404 Middleware
app.use((req, res, next) => {
const err = new Error("Page Not Found");
err.status = 404;
next(err);
});

// Global Error Middleware (Always Last)
app.use(errorMiddleware);
